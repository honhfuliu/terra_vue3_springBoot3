# Fix `buildMenuTree` — Multi-level Menu Support + Sorting

## Problem

`SysMenuServiceImpl.java:40-80` — `buildMenuTree` method:

1. **All root nodes (parentId=0) forced to `component="Layout"`**: Should only apply to directories (`menuType=M`), not menu pages (`menuType=C`).
2. **No `menuSort` ordering**: Children are in arbitrary order (depends on DB row order), not sorted by `menuSort`.
3. **Works for multi-level in theory** but sorting is missing and root-level handling is wrong.

## Plan

**File**: `src/main/java/com/ziheng/system/sysmenu/service/impl/SysMenuServiceImpl.java`

Replace the `buildMenuTree` method (lines 40-80) with:

### Changes

1. **Sort `menuList` first** by `parentId` then `menuSort` — this ensures children are added in correct order during tree assembly.
2. **Root node (parentId=0)**:
   - `menuType == "M"` → `component = "Layout"`, `path = "/" + path`
   - `menuType == "C"` → `component = "Layout"`, `path = "/" + path` (一级菜单在 Vue Router 中仍需 Layout 包裹侧边栏，但保留 menuType 信息以便前端区分)
3. **Keep the existing two-pass algorithm** (build map → assemble tree) — it naturally supports N-level menus via Java object references.
4. **No recursive sort needed** since flat list is pre-sorted — children are inserted in `menuSort` order.

### Final Code

```java
@Override
public List<SysMenuVO> buildMenuTree(List<SysMenu> menuList) {
    menuList.sort(Comparator.comparing(SysMenu::getParentId)
            .thenComparing(SysMenu::getMenuSort));

    Map<Long, SysMenuVO> menuMap = new HashMap<>();
    for (SysMenu menu : menuList) {
        SysMenuVO vo = new SysMenuVO();
        vo.setName(StringUtils.capitalize(menu.getPath()));
        vo.setPath(menu.getPath());
        vo.setComponent(menu.getComponent());
        vo.setVisible(menu.getVisible());
        vo.setPerms(menu.getPerms());
        vo.setMeta(new MetaVo(menu.getMenuName(), menu.getIcon()));
        menuMap.put(menu.getMenuId(), vo);
    }

    List<SysMenuVO> rootMenus = new ArrayList<>();
    for (SysMenu menu : menuList) {
        SysMenuVO current = menuMap.get(menu.getMenuId());
        if (menu.getParentId() == 0L) {
            current.setPath("/" + menu.getPath());
            if ("M".equals(menu.getMenuType())) {
                current.setComponent("Layout");
            }
            rootMenus.add(current);
        } else {
            SysMenuVO parent = menuMap.get(menu.getParentId());
            if (parent != null) {
                if (parent.getChildren() == null) {
                    parent.setChildren(new ArrayList<>());
                }
                parent.getChildren().add(current);
            }
        }
    }
    return rootMenus;
}
```
